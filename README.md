# Email to Telegram Bot

Пересылает одноразовые коды подтверждения из любого почтового ящика с доступом по IMAP в Telegram.

## Как работает

Бот держит одно IMAP-соединение и каждые несколько секунд ищет непрочитанные письма от указанных отправителей. Из найденного письма извлекается код и отправляется в Telegram, например `Service: 123456`. Код можно скопировать одним нажатием.

- Письмо загружается без пометки «прочитано». Отметка ставится только после успешной отправки в Telegram. Если отправка не удалась, бот повторит попытку в следующем цикле.
- Письма от других отправителей бот не трогает.
- Отправитель проверяется по точному адресу, а не по подстроке.
- Можно дополнительно ограничить обработку письмами на определённые адреса получателя, например алиасы ящика.
- Письма старше заданного возраста пропускаются, потому что код в них уже истёк.
- Сначала ищется код рядом с ключевыми словами. Если такого нет, берётся первое отдельно стоящее число нужной длины. HTML-цвета вроде `#123456` не учитываются.
- Поддерживаются письма только в HTML и любые кодировки, включая cp1251 и koi8-r.
- При ошибках пауза растёт до 5 минут, чтобы не блокировать ящик частыми входами.

## Настройка

Все параметры задаются переменными окружения. Скопируйте шаблон и заполните его. В шаблоне есть пояснения к каждой переменной.

```bash
cp .env.example .env
```

### Обязательные

| Переменная | Назначение |
|---|---|
| `EMAIL_SERVER` | IMAP-сервер, например `imap.gmail.com` |
| `EMAIL` | Логин ящика |
| `PASSWORD` | Пароль, обычно пароль приложения |
| `ALLOWED_SENDERS` | Адреса отправителей писем с кодами, через запятую |
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | ID чата или канала |

### Необязательные

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `IMAP_SECURITY` | `ssl` | `ssl` или `starttls` |
| `IMAP_PORT` | `993` для ssl, `143` для starttls | Порт сервера |
| `IMAP_FOLDER` | `INBOX` | Папка для поиска писем |
| `ALLOWED_RECIPIENTS` | пусто | Адреса получателя через запятую. Пусто означает «не проверять». |
| `MESSAGE_PREFIX` | пусто | Текст перед кодом в сообщении |
| `CODE_LENGTH` | `6` | Длина кода в цифрах |
| `CODE_KEYWORDS` | `код,code,пароль,password,otp` | Слова, рядом с которыми код ищется в первую очередь |
| `POLL_INTERVAL` | `10` | Интервал проверки в секундах |
| `MAX_EMAIL_AGE_MINUTES` | `15` | Письма старше этого возраста пропускаются |
| `IMAP_TIMEOUT` | `30` | Таймаут IMAP в секундах |
| `HTTP_TIMEOUT` | `10` | Таймаут запросов к Telegram в секундах |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

Файл `.env` содержит секреты. Он исключён из git и из Docker-образа.

### Настройки популярных почтовых сервисов

| Сервис | `EMAIL_SERVER` | Пароль |
|---|---|---|
| Rambler | `imap.rambler.ru` | Пароль приложения, IMAP включается в настройках |
| Яндекс | `imap.yandex.ru` | Пароль приложения |
| Mail.ru | `imap.mail.ru` | Пароль для внешних приложений |
| Gmail | `imap.gmail.com` | Пароль приложения, нужна двухэтапная аутентификация |

Имя папки с не-ASCII символами нужно указывать в кодировке IMAP UTF-7, как её показывает сервер.

```bash
venv/bin/python main.py
```
